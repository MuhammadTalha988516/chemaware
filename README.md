# ChemAware - Chemical Safety App 🧪✨

A modern, engaging mobile-first web application for chemical safety awareness with AI assistance.

## 🎨 Recent UI Enhancements

The app has been completely redesigned with modern UI/UX principles:

### ✨ Key Features
- **Smooth Animations** - Fade-in, slide-up, and scale animations throughout
- **Modern Design** - Gradient backgrounds, glass-morphism effects
- **Interactive Elements** - Hover effects, active states, micro-interactions
- **Loading States** - Skeleton screens and loading indicators
- **Empty States** - Beautiful empty state designs
- **Toast Notifications** - User feedback system
- **Floating Action Button** - Quick access to primary actions
- **Pull-to-Refresh** - Native-like refresh functionality

## 🚀 Tech Stack

- **React 18** - UI library
- **React Router** - Navigation
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **Vite** - Build tool
- **Supabase** - Backend (authentication & database)

## 📱 Pages

### Home
- Welcome header with time-based greetings
- Quick action buttons
- Progress statistics with circular indicators
- Recent scans history
- AI health tips
- Community impact stats

### Scanner
- Barcode scanning
- Photo upload
- Chemical search
- Real-time results

### AI Assistant
- Chat interface
- Suggested questions
- Chemical safety information
- Typing indicators

### Profile
- User information
- Statistics dashboard
- Achievements system
- Settings and preferences

## 🎯 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
